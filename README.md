# CanchaYa

Sistema de venta y gestión de entradas para partidos de fútbol desarrollado bajo metodología Spec-Driven Development.

## Estructura del Repositorio
* `docs/spec.md`: Especificación funcional y reglas de negocio (`RN-01` a `RN-05`).
* `docs/plan.md`: Plan técnico y modelo de base de datos.
* `docs/tareas.md`: Seguimiento de tareas.
* `docs/informe-pruebas.md`: Resumen de pruebas realizadas.
* `AGENTS.md`: Reglas y restricciones para agentes.
* `backend/`: API en Node.js + Express + PostgreSQL y pruebas unitarias.
* `frontend/`: Interfaz web en React + Vite.

## Despliegue
* Frontend: URL pública de Netlify (completar al publicar).
* Backend: URL pública de Render (completar al publicar).
* Base de datos: PostgreSQL en Neon.
